## 下载 APK

**下载地址**：[https://app.andru.de5.net/dl/passport.apk](https://app.andru.de5.net/dl/passport.apk)

- arm64 精简版（16MB，Android 5.0+ 64 位手机通用）
- 备用地址：GitHub Release `AndruGuo/passport-device` v0.1.0（私有仓库需登录）

## 安装步骤

1. 手机打开上面的下载链接，下载 APK
2. 点击安装 → 系统提示「未知来源」→ 去设置允许该来源「安装未知应用」
3. 安装完成，先打开一次 APP（暂时不要设为桌面）

## 首次验证

打开 APP 后应能看到三个页面：

- **工牌页**：黄色像素风身份卡（默认名 Andru、简介、首页短句）
- **游戏页**：贪吃蛇——按「确定」开始，上/下键转向，游戏中按确定键右转冲刺
- **设置页**：可编辑名称/简介/短句并保存，工牌页即时更新

验证清单：

- [ ] 三个页面都能正常显示
- [ ] 贪吃蛇能开始、转向、死后重来
- [ ] 设置页改名保存后工牌页同步更新
- [ ] APP 打开时屏幕常亮不熄屏

## 设备化（kiosk 模式）

1. 按「主页」键 → 系统弹出「选择桌面」→ 选 **Passport Device** → 点「始终」
2. 重启手机验证：开机应自动进入本 APP
3. 系统精简（手动完成，不刷机）：
   - 设置 → 应用管理：无关预装 APP 逐个「停用」（可逆）
   - 设置 → 账号：关闭自动同步
   - 开发者选项：三个动画缩放设为 0
   - 勿扰模式常开、深色主题

## 回到原桌面（随时可逆）

- 系统设置 → 应用管理 → Passport Device → 「默认打开」→ 清除默认设置
- 再按主页键 → 弹出桌面选择器 → 选回原厂桌面
- 原厂桌面从未被删除，随时可以切换回去

## 故障排查

| 现象 | 处理 |
|---|---|
| 安装提示「解析失败」 | APK 下载不完整，重新下载 |
| 按主页没弹选择器 | 设置 → 应用 → 默认应用 → 主页应用 → 手动选 Passport Device |
| 开机没进 APP | 重启一次；检查自启动权限 |
| 想卸载 | 直接卸载，桌面自动回落原厂桌面 |

## 技术信息

- Flutter 构建的 kiosk 应用，minSdk 21（Android 5.0+），目标机 Android 9 ✅
- 注册 HOME 桌面 + BOOT_COMPLETED 开机自启，无 root，完全可逆
- 屏幕常亮（wakelock）+ 沉浸式全屏 + 竖屏锁定
- 源码：GitHub 私有仓库 `AndruGuo/passport-device`
